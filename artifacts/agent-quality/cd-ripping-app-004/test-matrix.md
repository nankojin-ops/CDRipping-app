### 3.4 セキュリティ・パストラバーサル・予約名テスト（Security: TC-SEC）

#### TC-SEC-001: 相対パストラバーサル（`../` による親ディレクトリ脱出攻撃）
- **対象要件**: AC-001, AC-003
- **優先度**: P0 (Critical)
- **テストレベル**: Unit / Security
- **自動化区分**: 自動 (Automated)
- **前提条件**: `base_output_dir = "C:\Music\Output"`。
- **入力値**:
  - Case A: `album_artist = "../../Windows/System32"`
  - Case B: `album_name = "..\\..\\Escape"`
  - Case C: `track_title = "../../../boot.ini"`
- **手順**:
  1. `resolve_track_output_path` を呼び出す。
  2. 返却されたパスの絶対パスが `base_output_dir` 配下に収まっているか（`commonpath` 検証）を確認。
- **期待結果**:
  - トラバーサル文字 `..` がサニタイズ（例: `__` や削除）されるか、commonpath チェックにより逸脱が検知され、`base_output_dir` 配下に安全に封じ込められること。
  - 決して `C:\Windows` などの外部ディレクトリにファイルが作られないこと。
- **根拠**: 悪意あるCD-Textやメタデータによるファイル破壊・上書き攻撃の完全防止。

  - Case B: `album_name = "/etc/shadow"`

- **根拠**: Python の `os.path.join` の仕様（絶対パスが渡されると以前のパスを破棄する）による脆弱性の回避。

### 3.5 衝突回避・上書き防止テスト（Concurrency & Collision: TC-COL）

#### TC-COL-001: 同一セッション内での同名トラック衝突回避（`seen_output_paths`）
- **対象要件**: AC-001, AC-004
- **優先度**: P1 (High)
- **テストレベル**: Unit / Integration
- **自動化区分**: 自動 (Automated)
- **前提条件**: CD内に同一タイトル・同一トラック番号のタグが存在する異常ケース、または同一セッションで同じトラックを出力しようとするケース。
- **入力値**:
  - Track 1: `disc=1, trk=1, title="Intro"`
  - Track 2: `disc=1, trk=1, title="Intro"` (完全重複)
- **手順**:
  1. 1曲目のパスを解決して `seen_output_paths` に記録。
  2. 2曲目のパスを解決。
- **期待結果**:
  - 1曲目: `1-01 Intro.m4a`
  - 2曲目: `1-01 Intro_1.m4a`（または連番付与）
  - 同一セッション内で同一パスが重複して返されないこと。
- **根拠**: 意図しない上書きによるデータ消失防止。

#### TC-COL-002: ディスク上に既に同一ファイルが存在する場合の上書き防止
- **対象要件**: AC-001, AC-004
- **優先度**: P1 (High)
- **テストレベル**: Integration
- **自動化区分**: 自動 (Automated)
- **前提条件**: テスト先ディレクトリに `1-01 Song.m4a` が既に存在する。
- **入力値**:
  - `disc=1, trk=1, title="Song"`
- **手順**:
  1. `os.path.exists` チェックを含むファイルパス決定処理を実行。
- **期待結果**:
  - 既存ファイルを上書きせず、`1-01 Song_1.m4a` が生成されること。
- **根拠**: ユーザーの既存ファイルを不意に破壊しないための防御。

#### TC-COL-003: サニタイズによる名称縮約衝突
- **対象要件**: AC-001, AC-003
- **優先度**: P2 (Medium)
- **テストレベル**: Unit
- **自動化区分**: 自動 (Automated)
- **前提条件**: なし。
- **入力値**:
  - Track A: `title = "Song?"`
  - Track B: `title = "Song*"`
  （サニタイズ後、両者とも `"Song_"` になる場合）
- **手順**:
  1. 同一ディスク内で両トラックの出力パスを順次決定。
- **期待結果**:
  - 一方が `1-01 Song_.m4a`、もう一方が `1-02 Song__1.m4a` 等、一意のパスとして解決され衝突しないこと。
- **根拠**: サニタイズ起因の衝突ケースを防止。
